# Лабораторная работа № 1 по прикладной статистике

Авторы: 
Группа практики: ПрикСтат Инф25 1.3 

## Цель работы

Исследовать три случайные величины на химических данных:
изучить распределения и зависимости, проверить свойства оценок
и статистические гипотезы, затем реализовать генератор
на основе одной из исследованных величин.

## Данные

Датасет находится на этапе выбора.
Источник, единицы измерения и правила отбора будут зафиксированы
до основного анализа.

## Спринт 1 — статистическое исследование

- [ ] Выбрать и проверить датасет.
- [ ] Описать три случайные величины и случайный эксперимент.
- [ ] Проверить качество данных и обосновать обработку.
- [ ] Выполнить EDA.
- [ ] Рассмотреть распределения и их математические свойства.
- [ ] Выполнить и объяснить преобразования данных.
- [ ] Исследовать зависимости между величинами.
- [ ] Сравнить выборки с возвращением и без возвращения.
- [ ] Эмпирически исследовать состоятельность оценок.
- [ ] Проверить минимум одну статистическую гипотезу.
- [ ] Подготовить итоговые таблицы, выводы и список источников.

## Спринт 2 — генератор

- [ ] Выбрать величину и алгоритм генерации.
- [ ] Разобрать математическое обоснование.
- [ ] Реализовать генератор.
- [ ] Сравнить характеристики исходных и сгенерированных данных.
- [ ] Добавить автоматические тесты.
- [ ] Сформулировать выводы.
